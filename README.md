internet_test
This project contains an advanced script for internet quality analysis and network diagnostics.
The goal of this tool is to collect detailed information about network behavior—latency, jitter, DNS, MTU, routing, speed, and more—so the user can identify connectivity issues more accurately.
 Features
Ping tests to major endpoints (8.8.8.8, 1.1.1.1, google.com)
Jitter calculation
DNS resolution tests using multiple resolvers

MTU detection and fragmentation check

Traceroute execution and path analysis

System information collection (ifconfig, sysctl, uname, etc.)

Speedtest (speedtest-cli or Ookla official CLI)

HTTP download test
Automatic result storage in timestamped folders
Final summary generation for quick review
